# Canvi d'Unitat

Joc en català per practicar les **unitats de mesura i els seus canvis** (1r d'ESO): longitud (m), massa (kg), capacitat (L), superfície (m²) i volum (m³).

- **Escales** que mostren com es multiplica o es divideix per 10, 100 o 1 000 a cada pas.
- **Conversions** directes i **problemes reals** (p. ex. "La Paula vol caminar 1 km, quants metres ha de caminar?").
- **Modes** (com al CalcuHerois): Clàssic, Contrarellotge, Vides, Repte Progressiu, Boss Fight, Mode Cadena i Duel.
- XP, rangs, ratxes i trofeus guardats al navegador (localStorage). Sense comptes ni servidor.

Un sol fitxer: obre `index.html`. Afegeix `?selftest` a l'URL per executar l'autotest (comprova milers de preguntes amb aritmètica exacta).
